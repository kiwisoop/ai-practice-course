# 포트폴리오 제작 프롬프트와 진행 기록

[PRD.md](PRD.md)를 바탕으로 교재 02의 순서대로 진행한 기록입니다.

## 1. PRD → 5단계 프롬프트 변환

> 주어진 PRD를 클로드 코드에서 사용할 5단계 프롬프트로 변환해 줘.

| 단계 | 프롬프트 | 대응 요구사항 |
| :---: | --- | --- |
| 1 | PRD의 섹션 8개(`hero-introduction` ~ `contact`)로 HTML 구조를 만들어 줘. 섹션마다 고유 id를 붙이고, 상단 메뉴에서 각 섹션으로 이동하게 해 줘. 기능과 디자인은 아직 넣지 마. | FR-1~8 구조, FR-9 메뉴 |
| 2 | 페르소나(5년 차 퍼포먼스 마케터)에 맞게 실제 내용을 채워 줘. 스펙 요약 4개, 대표 프로젝트 3개는 과제 → 실행 → 결과로 써 줘. | FR-1~8 내용 |
| 3 | 대표 성과를 한눈에 보이게 Before/After 차트를 SVG로 그려 줘. 외부 라이브러리는 쓰지 마. | FR-1, How |
| 4 | 섹션마다 색 톤을 다르게 하고, 모바일 375px에서도 가로 스크롤이 없게 반응형으로 디자인해 줘. | FR-9, 완료 기준 |
| 5 | 모든 링크가 동작하는지, PRD와 다른 부분이 없는지 검토하고 고쳐 줘. 가상 정보라는 안내를 하단에 넣어 줘. | 완료 기준 전체 |

## 2. 4단계 포트폴리오 전략으로 실행

교재의 **뼈대 → 기능 → 디자인 → 점검** 순서로, 단계마다 요청 → 생성 → 확인 → 수정을 반복했습니다.

### ① 뼈대 → [steps/1-skeleton.html](steps/1-skeleton.html)

> 이 PRD대로 진행할 거야. 먼저 PRD를 기반으로 HTML 문서를 작성해 줘. 섹션을 나누고, 수정을 대비해 각 섹션에 고유한 이름을 붙여 줘. 아직 기능은 구현하지 말고, 전체 구조만 보여 줘.

- **확인:** 섹션 8개에 `hero-introduction`, `performance-metrics`, `about-me`, `case-studies`, `skills-tools`, `services`, `testimonials`, `contact` id가 붙었습니다.
- **수정 1:**
  > performance-metrics 섹션의 [프로젝트 수] 항목은 지난 3년 간의 성과를 구체적으로 나열한 리스트로 수정해 줘.

  → 2024·2025·2026년별 프로젝트 건수와 종류 목록으로 바꿨습니다.
- **수정 2:**
  > HTML 문서에 모던하고 세련된 디자인을 적용해 줘.
- **수정 3:**
  > case-studies 섹션에 있는 [Before/After 지표]를 hero-introduction 섹션으로 옮기고 차트로 표현해 줘.

  → 첫 화면에 브랜드 3곳의 월 매출 Before/After 막대 차트(SVG)를 넣었습니다.

### ② 기능 (실제 내용 채우기)

교재는 "실제 포트폴리오"를 전달하라고 합니다. 실습자는 마케터가 아니어서, PRD의 **가상 페르소나 정보**(경력·프로젝트·추천사)를 전달해 채웠습니다.

### ③ 디자인

> 워드프레스 테마 중에서 이 포트폴리오와 가장 잘 어울리는 것을 하나 선택해서 디자인을 수정해 줘. 섹션별로 색상 톤을 달리 해서 구분이 잘 되게 해 줘.

→ 워드프레스 포트폴리오 테마에서 흔히 쓰는 큰 타이포그래피 히어로, 카드형 케이스 스터디, 섹션별 배경 톤 구성을 참고했습니다(특정 테마 코드는 사용하지 않음). 섹션 톤은 크림 → 검정 → 흰색 → 하늘 → 연두 → 연보라 → 연노랑 → 남색 순입니다.

### ④ 점검

> 포트폴리오 웹페이지의 모든 부분이 잘 만들어졌는지 검토해 줘. PRD대로 제작되었는지, 각 링크가 문제없이 작동하는지 확인해.

브라우저에서 데스크톱(1024px)과 모바일(375px) 화면을 열고 스크립트로 검사했습니다.

| 검사 | 결과 |
| --- | --- |
| PRD 섹션 8개 존재 | ✅ 모두 있음 |
| 내부 링크(`#id`) 13개 | ✅ 끊어진 링크 0개 |
| 이메일 링크 | ✅ 2개 (`mailto:`) |
| 375px 가로 넘침 | ✅ 없음 |
| 가상 정보 안내 | ✅ 하단에 표시 |
| 콘솔 오류 | ✅ 없음 |

**발견한 개선점 3가지**

1. **모바일에서 상단 메뉴가 사라짐**: 900px 이하에서 메뉴를 숨겨 PRD FR-9(모바일에서도 섹션 이동)를 지키지 못했습니다.
2. **모바일에서 차트 글자가 8px로 작아짐**: SVG가 줄어들면서 글자도 같이 작아졌습니다.
3. **[프로젝트 수] 카드가 좁음**: 연도별 목록을 좁은 카드에 넣어 줄마다 2~3번씩 줄바꿈되었습니다.

> 발견된 개선점 3가지를 보완 및 수정하고, 완벽한 프리랜서 전환용 포트폴리오를 완성해.

| 개선점 | 수정 | 재확인 |
| --- | --- | --- |
| 1. 모바일 메뉴 | 로고 아래에 가로로 스크롤되는 메뉴로 표시 | 375px에서 메뉴 표시 ✅ |
| 2. 차트 글자 | 차트를 실제 너비에 맞춰 다시 그려 글자 크기 유지 | 375px에서 12px ✅ |
| 3. 프로젝트 카드 | 카드를 한 줄 전체로 넓히고 연도별 목록을 3열로 배치 | 데스크톱에서 목록이 나란히 표시 ✅ |
