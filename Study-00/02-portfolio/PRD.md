# PRD — 프리랜서 마케터 포트폴리오 웹페이지

교재 02 「프롬프트 활용」의 **기본 질문 템플릿(5W1H)** 으로 작성한 제품 기획서입니다.
교재 예시처럼 "취업을 준비 중인 프리랜서 마케터"를 가정했습니다. 인물·브랜드·수치는 모두 **실습용 가상 정보**입니다.

## 1. 기본 질문 템플릿 (5W1H)

| 요소 | 질문 | 답 |
| --- | --- | --- |
| **Why** (목적) | 왜 만드는가? | 프리랜서 퍼포먼스 마케터가 기업 채용 담당자·클라이언트에게 성과를 빠르게 보여 주고, 문의(전환)로 이어지게 하기 위해 |
| **Who** (대상) | 누구를 위한 것인가? | 마케터를 찾는 스타트업 대표, 브랜드 마케팅 팀장, 채용 담당자 |
| **What** (기능) | 무엇을 만들 것인가? | 소개, 핵심 성과 지표, 대표 프로젝트(케이스 스터디), 보유 역량, 서비스, 추천사, 연락처가 있는 한 페이지 포트폴리오 |
| **When** (사용 맥락) | 언제 사용되는가? | 지원서·제안서에 링크를 첨부했을 때, 담당자가 1~2분 안에 훑어보는 상황 |
| **Where** (사용 맥락) | 어디서 사용되는가? | PC 브라우저(사무실)와 스마트폰(이동 중) 모두 |
| **How** (구현 방법) | 어떻게 만들 것인가? | HTML·CSS·JavaScript 한 파일. 외부 라이브러리 없이 차트는 SVG로 그림. 섹션마다 고유 id를 붙여 수정하기 쉽게 구성 |

## 2. 페르소나 (가상)

- **이름:** 한서윤 (가상 인물)
- **직무:** 5년 차 퍼포먼스 마케터, 1년 전 프리랜서로 전환
- **강점:** 데이터 기반 광고 최적화, 그로스 실험, 콘텐츠 마케팅
- **목표:** 정규직 채용 또는 장기 프리랜스 계약

## 3. 요구사항

| ID | 섹션 (고유 id) | 내용 |
| --- | --- | --- |
| FR-1 | `hero-introduction` | 이름·한 줄 소개·대표 문구, 문의 버튼(CTA) |
| FR-2 | `performance-metrics` | 스펙 요약(Quick Stats): 경력, 관리 광고비, 평균 ROAS, 프로젝트 수 |
| FR-3 | `about-me` | 자기소개와 일하는 방식 |
| FR-4 | `case-studies` | 대표 프로젝트 3개: 과제 → 실행 → 결과, Before/After 지표 |
| FR-5 | `skills-tools` | 역량과 사용 도구 |
| FR-6 | `services` | 제공 서비스와 진행 방식 |
| FR-7 | `testimonials` | 클라이언트 추천사 |
| FR-8 | `contact` | 이메일·문의 안내, 맨 위로 이동 |
| FR-9 | 공통 | 상단 메뉴에서 각 섹션으로 이동, 모바일 화면 대응 |

## 4. 완료 기준

- 모든 섹션이 고유 id를 가지며, 상단 메뉴 링크가 해당 섹션으로 이동한다.
- 화면 너비 375px에서도 가로 스크롤 없이 읽힌다.
- 외부 서비스 없이 파일 하나로 열린다.
- 모든 링크가 동작한다(내부 이동, 이메일).
- 가상 정보라는 사실을 페이지 하단에 밝힌다.
