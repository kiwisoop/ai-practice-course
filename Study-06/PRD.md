## 2. 쇼핑 리스트 앱(`shopping-list.html`) 요구사항

### 핵심 기능
1. **상품 추가:** 입력창에 상품명을 입력하고 `Enter` 키 또는 `[추가]` 버튼을 누르면 목록에 추가된다.
2. **빈 입력 방지:** 공백만 입력하거나 빈 문자열로 추가를 시도하면 목록에 추가하지 않고 상태 안내 메시지를 표시한다.
3. **구매 완료 체크·해제:** 체크박스를 클릭하면 완료 스타일(취소선·배경 톤 변화)이 적용되고, 다시 클릭하면 원래 상태로 복구된다.
4. **상품 삭제:** 각 항목의 `[삭제]` 버튼을 누르면 해당 상품만 목록에서 제거되고 나머지 상품과 상태는 유지된다.
5. **실시간 요약 표시:** 하단에 `전체`, `완료`, `남음` 개수를 실시간으로 계산해 표시한다.
6. **새로고침 유지 및 예외 복구:** `localStorage`(`study06.shoppingList.v1`)에 상태를 자동 저장해 새로고침 후에도 복원한다. 저장소 용량 초과·접근 차단·손상된 JSON 데이터가 발생해도 화면 동작이 멈추지 않고 사용자에게 안내한다.

### 비기능 및 보안 요구사항
- **안전한 텍스트 표시:** 사용자 입력은 `innerHTML` 대신 `textContent`로만 렌더링해 `<script>`, `<img onerror=...>` 등 HTML/스크립트 주입이 실행되지 않도록 한다.
- **무의존성·무API 키:** 외부 JS/CSS 프레임워크나 유료 API 키 없이 브라우저에서 `shopping-list.html`만 열면 즉시 동작한다.
- **디자인 일관성:** 기존 수업 앱(Study-02~05)의 따뜻한 크림(`#faf6ed`)·브라운(`#4a3322`, `#89583c`) 색상을 참고하되 쇼핑 목록 관리에 집중한 간결한 카드 UI로 구성한다.

## 3. 자동 검증 기준 (`test_shopping_list.py`)

Playwright MCP(`@playwright/mcp`)로 실제 헤드리스 브라우저를 제어하여 아래 항목을 자동 검증하고 스크린샷을 남긴다.

1. 공백 입력 제출 시 거부 및 오류 상태 표시 확인 (`전체: 0` 유지)
2. `사과`, `우유`, `빵` 연속 추가 (`Enter` 키 및 `[추가]` 버튼 병행) 후 `전체: 3 / 완료: 0 / 남음: 3` 확인
3. `사과`, `우유` 구매 완료 체크 시 취소선·완료 상태(`완료: 2 / 남음: 1`) 확인 후, `사과` 체크 해제 시 원상 복구(`완료: 1 / 남음: 2`) 확인
4. `우유`, `빵` 삭제 시 해당 항목만 제거되고 `사과`만 남는지(`전체: 1 / 완료: 0 / 남음: 1`) 확인
5. 특수문자/태그 포함 텍스트 추가 및 새로고침 후 DOM 스크립트 미실행·데이터 복원 확인
6. `localStorage.setItem` 예외 발생 시 화면 유지 및 안내 메시지 확인, 손상된 JSON 저장값 복구 확인
