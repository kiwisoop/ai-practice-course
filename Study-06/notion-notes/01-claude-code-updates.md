확인일: 2026-11-17 (한국 시간)

## 공식 자료 확인

[공식 CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)의 현재 첫 버전은 **2.1.326**이다. 다음 내용은 이번에 직접 확인한 항목을 요약한 것이다.

- 에이전트 팀이 활성화된 상태에서 Code Mode를 사용할 수 있도록 지원한다.
- 잘못된 도구 권한 규칙을 시작할 때 경고하고, 권한·추가 경로 설정을 저장하지 못하면 알린다.
- 관리자 MCP 설정 적용으로 서버 로딩이 중단되는 이유를 안내한다.
- 로컬 MCP 서버 시작 실패 원인과 잘못된 add-json 설정을 더 구체적으로 설명한다.
- 재연결 대기 취소, MCP 도구의 복합 스키마 처리, 세션 재개와 되돌리기 관련 문제를 개선한다.

## 15주차 적용

MCP를 설치했다는 사실과 실제 도구 호출 성공을 구분한다. 인증 실패·설정 오류는 메시지를 확인하고 기록한다. 기존 문서는 다른 도구의 원격 Notion 연결에서 인증이 필요하다고 기록했지만, 이번 Codex 연결은 정상 인증되어 노트를 저장할 수 있다. 워크스페이스 연결 정보·이메일·토큰은 공개 실습 자료에 포함하지 않는다.

위 버전은 확인 당시 기준이며, 모든 계정의 기능 제공이나 이후 업데이트를 보장하지 않는다. 전체 변경 내역은 공식 원문을 확인한다.
