## 기존 작업과 이번 보완

Study-06에는 쇼핑 리스트·검사 스크립트·리서치·추론 비교 문서가 이미 작성되어 있었다. 이를 보존해 재검증하고 아래를 보완했다.

- 손상된 저장 데이터를 읽은 뒤 새 입력으로 원본을 덮어쓸 수 있던 경로를 수정했다. JSON·필드·중복 ID 검증 실패 시 자동 저장을 중지한다.
- 잘못된 저장 기록 이후 상품을 추가해도 원본이 유지되는 회귀 검사를 추가했다.
- 검사 종료 시 기존 `.playwright-mcp` 폴더를 통째로 지우던 코드를 제거했다. 직접 만든 임시 출력 폴더만 정리한다.
- 이전의 Notion 인증 미완료 기록을 현재 Codex 연결의 실제 저장 결과로 갱신했다.

## Playwright MCP 6개 시나리오

1. 빈 입력 거부·오류 안내
2. 사과·우유·빵 추가와 집계
3. 구매 체크·해제와 취소선·집계 변경
4. 우유·빵 삭제 시 사과 보존
5. 새로고침 복원·HTML 문자열 미실행
6. 저장 실패 시 화면 유지·손상 JSON과 잘못된 필드 원본 보존

실행: `python3 Study-06/test_shopping_list.py`. 검사는 개인 브라우저·실제 사용자 목록을 사용하지 않는다. `screenshots/`에는 테스트용 항목의 단계별 캡처 4장을 보관한다.
