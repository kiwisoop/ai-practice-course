```

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ 현재 대학생들의 불편함

  • 시간 부족: 한 과목만 복습해도 1-2시간 필요
    → 여러 과목 복습 불가능

  • 비효율적 복습: 모든 내용을 다시 읽음
    → 중요한 내용에 집중 불가

  • 복습 동기 부족: 혼자서 반복학습은 지루함
    → 복습 중단율 높음


✅ 프로젝트의 해결 방법

  AI를 활용한 자동 요약 + 대화형 복습 시스템
  
  1단계: AI가 강의 노트를 자동으로 요약
  2단계: 핵심 개념을 뽑아내고 복습 질문 생성
  3단계: AI 튜터와 대화하며 복습
  4단계: 개인화된 복습 일정 추천
```

**발표 스크립트**:
```
먼저 문제를 정의하겠습니다.

대학생들은 매학기 10개 이상의 과목을 듣는데,

문제는 세 가지입니다:

첫째, 시간 부족입니다. 
한 과목만 복습해도 1-2시간이 걸려서, 
여러 과목을 효율적으로 복습하기 어렵습니다.

둘째, 비효율적인 복습입니다.
모든 내용을 다시 읽다 보니 중요한 내용에 집중하지 못합니다.

셋째, 복습 동기 부족입니다.
혼자서 반복학습은 매우 지루해서 중단율이 높습니다.

이 문제들을 해결하기 위해 AI를 활용합니다.
AI가 강의 노트를 자동으로 요약하고,
AI 튜터와 대화하면서 효율적으로 복습할 수 있게 합니다.
```

### 📌 슬라이드 6: AI 개선 과정 (40초)

**슬라이드 제목**: AI 협업 과정 및 개선 사례

**슬라이드 내용**:
```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   AI 협업 과정 및 개선 사례 (3가지)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📝 사례 1: 요약 프롬프트 개선

초기 프롬프트:
  "이 텍스트를 요약해줄래?"

결과: 너무 짧고 불완전한 요약
문제점: 요약 비율과 중요도를 명확히 하지 않음

개선된 프롬프트:
  "이 강의 노트를 다음 조건으로 요약해줄래:
   - 70% 길이 유지
   - 핵심 개념은 굵게 표현
   - 예시는 최소화
   - 마크다운 형식 사용"

결과: ✓ 체계적이고 명확한 요약 완성


📝 사례 2: 질문 생성 품질 개선

초기 프롬프트:
  "10개의 복습 질문을 만들어줄래?"

결과: 너무 쉬운 질문들
문제점: 질문 난이도와 형식을 지정하지 않음

개선된 프롬프트:
  "이 내용으로 복습 질문 10개를 만들어줄래.
   - 5개는 객관식 (4지선다)
   - 3개는 단답형
   - 2개는 서술형 심화 질문
   - 답안도 함께 제공"

결과: ✓ 다양한 난이도와 형식의 질문 완성


📝 사례 3: AI 피드백 개선

초기 상황:
  학생 답변 → AI 평가 → "맞습니다/틀렸습니다"

문제점: 너무 단순한 피드백, 학습 효과 낮음

개선된 프롬프트:
  "학생 답변을 다음 기준으로 평가해줄래:
   1. 정확성 평가
   2. 부족한 부분 지적
   3. 올바른 설명 제공
   4. 이해를 돕는 추가 예시 2개"

결과: ✓ 상세하고 교육적인 피드백 완성
```

**발표 스크립트**:
```
AI 협업 과정에서 중요한 것은 프롬프트를 계속 개선하는 것입니다.

사례 1: 초기에는 "이 텍스트를 요약해달라"고만 했는데,
결과가 너무 짧고 불완전했습니다.
그래서 프롬프트를 개선해서 "70% 길이를 유지하고,
핵심 개념은 굵게, 예시는 최소화"라고 명시했더니,
훨씬 더 체계적인 요약이 나왔습니다.

사례 2: 질문 생성도 처음에는 너무 쉬운 질문들만 만들어졌습니다.
그래서 "객관식 5개, 단답형 3개, 서술형 2개"라고 형식을 명시했더니,
다양한 난이도의 질문이 생성되었습니다.

사례 3: AI 피드백도 초기에는 "맞습니다/틀렸습니다"만 했는데,
프롬프트를 개선해서 "정확성 평가, 부족한 부분 지적, 올바른 설명, 추가 예시"를 요청했더니,
훨씬 교육적인 피드백이 나왔습니다.

이렇게 AI와 협업하면서 프롬프트를 계속 개선하는 것이 핵심입니다.
```

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
         최종 결과물 시연
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🖥️ 시연 순서 (스크린샷/라이브 데모)

[화면 1] 메인 페이지
└─ 강의 노트 입력 화면
   • 텍스트 직접 입력
   • 파일 업로드 (또는 카메라 촬영)
   
[화면 2] AI 처리 중 (로딩)
└─ "AI가 강의 노트를 분석 중입니다..."

[화면 3] 처리 완료 - 대시보드
└─ 📊 처리 결과 요약:
   ✓ 원본 길이: 1,250 단어
   ✓ 요약본 길이: 850 단어
   ✓ 핵심 개념 10개 추출
   ✓ 복습 질문 10개 생성 완료

[화면 4] 요약 내용 보기
└─ 📝 요약된 강의 노트
   ───────────────────────
   [생물학 - 세포의 구조]
   
   • 세포 (Cell)
     * 생명의 기본 단위

     * 모든 세포는 다른 세포에서 나옴
   
   • 세포의 종류
     * 원핵세포: 핵이 없음 (박테리아)
     * 진핵세포: 핵이 있음 (동물, 식물)
   
   • 세포 소기관
     ...

[화면 5] 핵심 개념 확인
└─ 📌 추출된 핵심 개념
   1. 세포 (Cell): 생명의 기본 단위
   2. 원핵세포: 핵이 없는 세포
   3. 진핵세포: 핵이 있는 세포
   4. 미토콘드리아: 세포의 에너지 발전소
   5. 핵: 유전정보 저장 장소
   ... (총 10개)

[화면 6] 복습 모드 시작
└─ 🎯 복습 준비 완료
   
   문제 1/10
   ───────────────────────
   Q. 다음 중 세포의 가장 중요한 기능은?
   
   ① 단백질 합성
   ② 에너지 생성 및 저장
   ③ 환경 반응
   ④ 생식
   
   [학생이 답변 선택]

[화면 7] AI 피드백
└─ ✓ 정답입니다!
   
   설명:
   세포는 에너지 생성과 저장이 주요 기능입니다.
   미토콘드리아라는 소기관에서 ATP(에너지)를

   추가 설명:

   • 근육 세포는 미토콘드리아가 많음 (에너지 필요)
   
   [다음 문제로]

[화면 8] 복습 일정 추천
└─ 📅 개인화된 복습 일정
   
   복습 현황: 10문제 중 8문제 정답 (80%)
   
   추천 복습:
   • 내일: 틀린 2문제 복습 추천
   • 3일 후: 전체 내용 복습
   • 1주 후: 심화 질문 도전
   
   [복습 알림 설정]
```

```
[화면 5 설명]
```

### 📌 슬라이드 8: 마무리 (30초)

**슬라이드 제목**: 마무리 및 창의성 포인트

**슬라이드 내용**:
```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
    마무리 및 창의성 포인트
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✨ 이 프로젝트의 창의성

1️⃣ 단순 요약을 넘어 "학습 플랫폼"
   - 기존: 단순 요약 도구
   - 개선: 요약 + 질문 + 피드백 + 일정 추천
   - 가치: 완전한 학습 경험 제공

2️⃣ AI와의 "상호작용"
   - 기존: 일방적 AI 생성
   - 개선: 학생 답변에 대한 AI 피드백
   - 가치: 튜터링 경험 제공

3️⃣ Spaced Repetition 적용
   - 기존: 사용자가 복습 시기 결정
   - 개선: AI가 과학적으로 복습 시기 추천
   - 가치: 최적의 학습 효율성


📈 기대 효과

✓ 복습 시간: 50% 감소
✓ 학습 효율: 30% 증가
✓ 학습 동기: 대화형 상호작용으로 증가


🔮 향후 개선 계획

• 이미지 OCR: 사진으로 찍은 필기도 인식
• 멀티 톤: 복습 톤 변경 (엄격한 튜터 vs 친근한 친구)
• 협력 기능: 같은 과목 친구들과 복습 질문 공유
• 모바일 앱: 언제 어디서나 복습 가능


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

감사합니다!

질문이 있으신가요?
```

**발표 스크립트**:
```
이 프로젝트의 창의성은 세 가지입니다.

첫째, 단순 요약을 넘어 완전한 학습 플랫폼을 만들었습니다.
기존 프로젝트들은 텍스트를 요약만 하는 데 반해,
이 프로젝트는 요약, 개념 추출, 질문 생성, 피드백, 복습 일정까지 모두 포함합니다.

둘째, AI와의 상호작용을 강조했습니다.
학생이 답변하면 AI가 즉시 피드백을 주는 튜터링 경험을 제공합니다.

셋째, Spaced Repetition이라는 과학적 복습 방법을 적용했습니다.
단순히 복습하라고 하는 게 아니라,
최적의 복습 시기를 AI가 추천해줍니다.

기대 효과는:
- 복습 시간을 50% 단축
- 학습 효율을 30% 증가
- 대화형 상호작용으로 학습 동기 증가

향후에는 이미지 OCR, 복습 톤 변경, 협력 기능, 모바일 앱 등으로 확장할 수 있습니다.

감사합니다. 질문이 있으신가요?
```
