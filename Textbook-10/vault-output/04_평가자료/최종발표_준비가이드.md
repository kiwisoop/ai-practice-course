## 🎯 발표 필수 포함 항목 (5분 안에 커버)

### 1️⃣ 프로젝트 개요 (30초)
> 어떤 문제를 어떻게 해결하는 프로젝트인가?

**발표 스크립트**:
```
예시: "안녕하세요, [프로젝트 제목]입니다. 
이 프로젝트는 [구체적 문제]를 [AI 기술]을 활용하여 
[해결 방법]하는 [결과물 형태]입니다."
```

### 2️⃣ 문제 정의 및 필요성 (1분)
> 왜 이 문제를 해결해야 하는가?

**포함할 내용**:
- [ ] 해결하려는 구체적 불편함
- [ ] 현재 사용자들의 불편함 (통계/예시)
- [ ] 기존 방식의 한계
- [ ] 프로젝트를 통해 얻을 수 있는 이점

### 3️⃣ 대상 사용자 및 사용 상황 (20초)
> 누가 어떻게 사용할 것인가?

**발표 스크립트**:
```
"주요 사용자는 [구체적 페르소나]이며, 
[구체적인 상황/시간]에 [구체적인 목적]으로 사용하게 됩니다."
```

### 4️⃣ 핵심 기능 소개 (1분 30초)
> 어떤 기능들이 문제를 해결하는가?

**각 기능별 설명 (30초/기능)**:
- **기능명**: 
  - 역할: 
  - 왜 필요한가: 
  - 어떻게 구현했는가: 

### 5️⃣ AI 활용 사례 및 개선 과정 (1분 30초)
> AI를 어떻게 활용했고, 어떻게 개선했는가?

**반드시 포함할 내용**:
- [ ] 사용한 AI 도구 (ChatGPT/Claude/etc)
- [ ] AI를 활용한 구체적 사례 (3개 이상)
  - 예1: "[상황] 때 AI에게 [프롬프트 요청] → [결과] → [검토] → [개선]"
  - 예2: "[상황] 때 발생한 [오류] → AI 활용으로 [해결]"
- [ ] 오류 발생 시 해결 과정
- [ ] 최종 결과물까지의 개선 과정

### 6️⃣ 결과물 시연 (1분 30초)
> 실제로 작동하는 프로젝트를 보여줄 것

**시연 준비 체크리스트**:
- [ ] 결과물이 완벽하게 작동하는가?
- [ ] 모든 핵심 기능을 시연할 수 있는가?
- [ ] 오류 발생 가능성은 없는가?
- [ ] 시연 시나리오를 미리 준비했는가?

### 7️⃣ 주요 의사결정 및 창의성 (30초)
> 이 프로젝트의 창의성은 무엇인가?

**발표 스크립트**:
```
"주요 창의성 포인트는:
- [다른 프로젝트와의 차별점]
- [아이디어의 독창성]"
```
