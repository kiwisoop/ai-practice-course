## 📋 프로젝트 개요

### 기본 정보
- **수행 방식**: 개인 프로젝트 (1인 1프로젝트, 팀 구성 불가)
- **프로젝트 주제**: 자유 주제 (AI 기술 또는 생성형 AI 도구를 실질적으로 활용)
- **평가 대상**: 결과물뿐만 아니라 AI와 협업하며 문제를 해결한 과정

## 🎯 주제 선정 기준 (가장 중요)

### ✅ 권장되는 주제
- **문제 중심**: 일상생활, 학습, 전공 분야에서 실제 불편함을 해결하는 프로젝트
- **구체성**: 대상 사용자를 명확하게 설정 (예: 누가, 어떤 상황에서 사용)
- **독창성**: 기존 방식의 한계를 명확히 제시
- **실현 가능성**: 주어진 기간 내에 완성 가능한 규모

### ❌ 피해야 할 주제
- 단순 계산기, 로그인 화면, 기본 날씨 앱 등 흔한 기능의 단순 복제
- 프로젝트 규모는 큼에도 아이디어가 흔함

### 📌 핵심 평가 포인트
> **프로젝트 규모 < 독창성, 실현 가능성, 해결하려는 문제의 가치**  
> 작지만 창의적이고 실용적인 프로젝트가 큰 규모의 흔한 프로젝트보다 평가받음

## 📌 수행 방법: 프로세스 단계별 기록

### 프로세스 흐름
```
문제 정의 
  ↓
요구사항·핵심 기능 정리 
  ↓
AI 활용 계획 
  ↓
구현 
  ↓
테스트 및 오류 수정 
  ↓
결과 개선 
  ↓
기록·발표
```

### ⭐ 가장 중요한 평가 항목: AI 협업 과정 기록

**반드시 기록할 항목:**
1. **AI에게 요청한 내용** (프롬프트)
2. **AI의 응답·생성 결과**
3. **직접 검토한 내용** (문제점, 개선사항)
4. **수정 판단 및 실행**

**예시:**
- ❌ "ChatGPT에게 코드를 작성하게 했다"
- ✅ "[프롬프트] '로그인 기능을 Flask로 구현해줄래?' → [결과] 코드 생성 → [검토] SQL injection 위험 발견 → [수정] 프롬프트 변경하여 보안 강화 요청 → [결과] 개선된 코드 적용"

**기능이 처음부터 작동하지 않은 경우:**
- 오류 원인 분석
- 프롬프트 변경 과정
- 해결 과정을 보여주는 것이 평가에 긍정적

## 📊 주제 발표 자료 필수 포함 내용

### 1️⃣ 프로젝트 제목·요약
- 어떤 문제를 어떻게 해결하는지 간략히 설명

### 2️⃣ 문제와 선정 배경
- 해결하려는 불편함
- 필요성
- 기존 방식의 한계

### 3️⃣ 대상 사용자
- 누가 어떤 상황에서 사용할 것인지 구체적으로 설정

### 4️⃣ 핵심 기능
- 3~5개 권장
- 기능별 역할과 필요한 이유 설명

### 5️⃣ AI 도구 및 활용
- 사용 예정 AI 도구
- 사용 단계
- 예상 프롬프트 예시

### 6️⃣ 단계별 실행 계획
- 기능 구현 순서
- 검증 방법
- 예상 난관과 대응 방안

### 7️⃣ 예상 결과물
- 프로그램, 웹앱, 노트북, 분석 결과 등 최종 형태

## 📈 평가 기준 (총 100점)

| 평가 항목 | 배점 | 핵심 평가 내용 |
|----------|------|----------------|
| **주제 참신성** | 20점 | 문제의 명확성, 독창성, 구체적인 사용자와 가치 |
| **기획의 구체성** | 25점 | 목적·기능·도구·결과물 및 구현 순서의 명확성 |
| **AI 활용 계획·수행** | 25점 | 단계별 프롬프트 전략, AI 활용, 오류 대응 |
| **진행 과정 기록** | 20점 | 실제 프롬프트·결과·수정·개선 내역의 충실성 |
| **최종 발표** | 10점 | 진행 과정과 주요 의사결정, 결과물 시연의 명확성 |

### 💡 평가 전략
1. **참신성 (20점)**: 주제 선정이 가장 중요. 창의적이고 명확한 문제 정의
2. **기획 (25점)**: 세부 계획과 실행 가능성. 모든 항목 구체적으로 작성
3. **AI 활용 (25점)**: 가장 큰 비중. 프롬프트 전략과 실제 협업 과정 기록
4. **기록 (20점)**: 과정 투명성. 모든 단계에서 프롬프트·결과·수정 기록
5. **발표 (10점)**: 명확한 시연과 의사결정 설명
