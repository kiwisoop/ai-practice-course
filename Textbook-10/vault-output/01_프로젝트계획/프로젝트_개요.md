## 2. 프로젝트 한 문장 요약

> AI를 활용하여 강의 노트를 자동 요약하고, 대화형 복습 시스템을 통해 학생들의 복습 시간을 50% 단축하는 웹 애플리케이션

---

## 3. 문제 정의 및 선정 배경

### 3.1 해결하려는 구체적인 문제
- **시간 부족**: 한 과목 복습만 1-2시간 필요 → 여러 과목 복습 불가능
- **비효율적 복습**: 모든 내용을 다시 읽음 → 중요한 내용 집중 불가
- **복습 동기 부족**: 혼자서 반복학습은 지루함 → 복습 중단율 높음

### 3.2 문제의 필요성
대학생들은 매학기 10개 이상의 과목을 듣지만, 광범위한 강의 노트를 복습하기 위한 체계적인 도구가 부족합니다. 특히 시험 준비 기간에 여러 과목을 효율적으로 복습하는 것이 매우 어렵습니다.

### 3.3 기존 방식의 한계
- **수동 요약**: 직접 중요한 부분을 표시하고 요약 → 시간 오래 걸림
- **단순 반복학습**: 텍스트를 반복해서 읽음 → 이해도 확인 불가
- **복습 일정 미흡**: 언제 복습할지 명확하지 않음 → 중요한 내용 재학습 놓침

## 4. 대상 사용자

### 4.1 주요 사용자 페르소나
**이름**: 김 대학생  
**나이/직업**: 20대 대학생 (2학년 이상)  
**상황**: 시험 1주일 전, 도서관이나 집에서 여러 과목을 짧은 시간에 복습해야 하는 상황  
**해결되는 불편함**: 복습 시간을 절반으로 단축, 중요한 내용에 집중 가능, 혼자가 아닌 AI 튜터와 함께 복습

### 4.2 사용자 수 및 범위
- **1차 대상**: 한국 대학생 약 150만 명
- **2차 대상**: 공무원 시험 준비생, 온라인 강의 수강자, 자격증 준비생
- **당면 목표**: 한 학교(목포대) 학생 대상 테스트 (약 2,000명)

## 5. 핵심 기능 (5개)

### 기능 1: 자동 텍스트 요약
- **역할**: 강의 노트를 70-80% 길이로 자동 축약
- **필요한 이유**: 시간 절약, 핵심 내용 강조
- **구현 방법**: Claude AI의 요약 프롬프트 활용

### 기능 2: 핵심 개념 추출
- **역할**: 중요한 개념/정의/공식을 불릿 포인트로 추출
- **필요한 이유**: 한눈에 중요한 내용 파악 가능
- **구현 방법**: AI의 텍스트 분석 및 마크다운 구조화

### 기능 3: 자동 복습 질문 생성
- **역할**: 강의 내용 기반 10개의 복습 질문 자동 생성
- **필요한 이유**: 대화형 복습으로 이해도 확인 및 적극적 학습
- **구현 방법**: AI의 질문 생성 프롬프트 (객관식, 단답형, 서술형 혼합)

### 기능 4: AI 튜터와의 대화
- **역할**: 사용자 답변에 대한 피드백 및 상세 설명 제공
- **필요한 이유**: 모르는 부분 즉시 해결, 튜터링 경험 제공
- **구현 방법**: Claude와의 대화형 인터페이스, 평가 프롬프트

### 기능 5: 복습 일정 추천
- **역할**: Spaced Repetition 알고리즘으로 최적의 복습 날짜 추천
- **필요한 이유**: 과학적 복습으로 장기 기억 강화
- **구현 방법**: 복습 간격 계산 로직 + AI 추천 프롬프트

## 6. 예상 결과물

### 6.1 최종 결과 형태
- [x] **웹 애플리케이션** (Python Flask/Django + HTML/CSS/JS)
- [ ] 데스크톱 프로그램
- [ ] 모바일 앱
- [ ] Python 스크립트/노트북

### 6.2 결과물의 구체적 설명

**사용 흐름**:
1. 사용자가 강의 노트를 텍스트 입력 또는 파일 업로드
2. AI가 처리 (로딩 화면)
3. 대시보드에 처리 결과 표시:
   - 원본 길이 vs 요약본 길이
   - 추출된 핵심 개념 10개
   - 생성된 복습 질문 10개
4. 사용자가 "복습 모드" 선택
5. 각 질문마다:
   - 질문 표시
   - 사용자 답변 입력
   - AI 피드백 표시
6. 모든 질문 완료 후 복습 일정 추천

**주요 화면**:
- 메인 페이지: 강의 노트 입력 화면
- 대시보드: 처리 결과 요약
- 요약 보기: 체계적으로 정리된 요약 본문
- 개념 목록: 추출된 핵심 개념 10개
- 복습 모드: 질문-답변-피드백 반복
- 복습 일정: 추천된 복습 시기

### 7.2 AI를 활용할 단계 및 목적

| 단계 | AI 활용 목적 | 기대 효과 |
|------|------------|---------|
| 계획 | 프로젝트 아이디어 평가, 기능 개선 아이디어 | 더 창의적이고 실용적인 설계 |
| 구현 | 웹앱 백엔드/프론트엔드 코드 생성 | 개발 시간 50% 단축 |
| 프롬프트 개선 | 각 기능별 프롬프트 테스트 및 최적화 | 더 정확하고 명확한 결과 |
| 검증 | 생성 결과 평가, 오류 분석 및 수정 | 버그 발견 및 성능 개선 |

### 7.3 예상 프롬프트 예시

#### 프롬프트 1: 텍스트 요약
```
"다음 강의 노트를 70% 길이로 요약해줄래. 조건:
- 핵심 개념은 **굵게** 표현
- 번호 없는 불릿 포인트 사용
- 예시는 최소화
- 마크다운 형식 사용"
```

#### 프롬프트 2: 복습 질문 생성
```
"위 강의 내용으로 복습 질문 10개를 만들어줄래.
- 5개는 객관식 (4지선다, 1개만 정답)
- 3개는 단답형
- 2개는 서술형 심화 질문
각 질문 아래 정답과 풀이 포함"
```

#### 프롬프트 3: AI 피드백
```
"학생이 '[학생 답변]'이라고 답했어.
다음 기준으로 평가하고 피드백 줄래:
1. 정답 여부 판단
2. 부족한 부분 지적
3. 올바른 설명 제공
4. 이해 돕는 추가 예시 2개"
```
