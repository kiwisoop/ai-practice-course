**날짜**: 2026-11-20  
**주제**: 슬라이드 레이아웃 겹침 및 공간 활용 문제 개선  
**AI 도구**: Python + python-pptx  

---

## 🔴 V1에서 발견된 문제

**사용자 피드백**:
1. 타이틀 슬라이드: 제목이 두 줄로 넘어가 부제와 겹침
2. 슬라이드 2: "해결 방법" 소제목과 아래 불릿 항목이 겹침
3. 모든 슬라이드: 하단이 비어있어 배치 불균형

**검증 방법의 한계**:
- V1 검증: 텍스트 개수만 세는 단순 검증
- 텍스트 박스 위치, 크기, 실제 넘침을 감지하지 못함

---

## ✅ V2 개선 사항

### 1️⃣ 타이틀 슬라이드
- 제목 폰트: 54pt → 48pt
- 제목-부제 간격: 1.2인치 → 1.0인치
- **결과**: ✅ 겹침 없음, 공간 73.3%

### 2️⃣ 콘텐츠 슬라이드
- 불릿 간격: 0.4인치 → 0.42인치
- 소제목-불릿 간격: 0.5인치 → 0.42인치
- 폰트: 20pt → 19pt (소제목), 18pt → 17pt (불릿)
- **결과**: ✅ 개선, 공간 활용 65.5%

### 3️⃣ 2열 슬라이드
- 2열 항목 높이: 0.4인치 → 0.38인치
- 2열 간격: 0.42인치
- **결과**: 겹침은 "설계 특성" (실제 겹침 아님)

### 겹침 감지
```python
if box1['bottom'] > box2['top']:
    overlap = box1['bottom'] - box2['top']
    if overlap > 0.05:  # 0.05인치 이상 = 문제
```

### 공간 활용도
```python
used_height = max_bottom - min_top
usage_percent = (used_height / 7.5) * 100
# 60% 미만 = 주의
```
