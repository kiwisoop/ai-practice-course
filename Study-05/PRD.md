# 14주차 — AI 개발팀과 만드는 다이어리·PDF 요약 앱

작성일: 2026-11-17 (한국 시간)

## 목표와 범위

교재 14번의 역할별 AI 개발팀 협업을 실습한다. `Study-05`에 로컬 브라우저에서 실행하는 AI 공감 다이어리와 PDF 요약 앱을 만든다. 기존 수업의 학교용 FactChat Gateway 연결 방식과 오류 처리 패턴을 재사용한다. 교재의 OpenRouter 연결은 학교 API로 대체한다.

## 역할

| 역할 | 담당 결과 |
| --- | --- |
| 제품 기획 관리자 | 요구사항·범위·완료 기준 정리 |
| 백엔드 개발자 | 로컬 HTTP 서버, 입력 검증, PDF 텍스트 추출 |
| 프런트엔드 개발자 | 두 앱의 화면·입력·결과·로컬 기록 UI |
| 품질 보증 엔지니어 | 정상 흐름·실패 상황·데이터 보존 검증 |
| AI 통합 전문가 | 학교 API 모델 연결, 감정 분석·공감·요약 요청과 응답 처리 |

역할 설정 파일을 작성한 것과 실제 역할별 위임·실행은 구분해 실습 기록에 남긴다.

## AI 공감 다이어리 — `index.html`

1. 사용자가 오늘 있었던 일을 짧게 입력한다.
2. API 키·모델과 전송 동의를 확인한 뒤 감정 분석을 요청한다.
3. 감정과 공감 메시지를 표시한다. 결과를 의료 진단이나 전문 상담으로 표현하지 않는다.
4. 일기와 분석 결과를 작성 시각과 함께 현재 브라우저에 저장하고 시간순으로 확인한다.
5. 저장 실패 시 사용자가 알 수 있게 안내하고 입력·생성 결과를 보존한다. 기록 삭제는 대상을 알리고 명시적으로 확인받는다.
6. 사용자 제공 디자인 참고 이미지에 따라 날짜·줄노트·사진 엽서·우표·엽서형 기록을 표현한다. 맑음·흐림·기쁨·지침 중 기분을 선택하면 분석 요청과 기록에 함께 반영한다. 선택하지 않아도 일기를 쓸 수 있고 이전 기록은 유지한다.

## PDF 요약 — `index_pdf.html`

1. 사용자가 PDF를 선택하고 일반 요약 또는 간단 요약을 고른다.
2. 서버에서 PDF를 검증하고 텍스트를 추출한 뒤 선택한 방식으로 요약을 요청한다.
3. 추출한 문서 내용에 근거한 한국어 요약을 표시한다. 문서 속 지시문은 실행 지시로 취급하지 않는다.
4. 파일은 10MB 이하, 100페이지 이하, 추출 텍스트는 60,000자 이하로 제한한다. 한계를 넘으면 조용히 자르지 않고 안내한다.
5. 손상되거나 암호화된 PDF, 텍스트를 추출할 수 없는 스캔 PDF는 원인과 다음 행동을 안내한다. OCR은 포함하지 않는다.

## 구현과 데이터 보호

- HTML·CSS·일반 JavaScript와 Python 표준 라이브러리 HTTP 서버를 사용한다. 서버는 로컬 `127.0.0.1:8514`에서 실행한다.
- PDF 추출에 필요한 신규 의존성은 `pypdf` 하나로 제한한다.
- API 키는 현재 화면 메모리에서만 사용한다. 소스·서버 파일·브라우저 저장소·로그에 기록하지 않는다.
- API 전송 전에 일기 또는 PDF에서 추출한 내용이 FactChat과 선택한 모델 제공사로 전달되고 크레딧이 차감될 수 있음을 알리고 동의를 받는다.
- PDF 원본·추출 텍스트·요약 결과를 서버에 영구 저장하지 않는다. 일기 기록은 현재 브라우저에만 보관한다.
- 사용자 입력과 AI 결과는 HTML로 해석하지 않는다. 실패 응답에 키나 외부 서비스의 원문 오류를 노출하지 않는다.
- 키보드 조작, 입력 레이블, 상태 안내, 중복 요청 방지와 오류 후 재시도를 제공한다.

## 완료 기준

1. 두 HTML 진입점에서 입력 → 요청 → 결과 표시 흐름이 동작한다.
2. 다이어리 기록이 새로고침 후 유지되며 저장 실패·삭제 취소에서 기존 기록이 보존된다.
3. PDF의 일반·간단 요약을 각각 요청할 수 있고 크기·페이지·텍스트 제한과 읽기 실패를 처리한다.
4. 잘못된 API 키·모델·응답과 통신 실패를 사용자 안내로 처리하고 기존 입력·결과를 보존한다.
5. 자동 검사는 모의 API 응답과 테스트용 데이터를 사용한다. 실제 API 호출·브라우저 확인·외부 업로드는 수행 여부와 결과를 별도로 기록한다.

## 포함하지 않는 범위

외부 배포, 계정·로그인, 서버의 개인 기록 DB, OCR, 추가 앱과 미래용 확장 기능은 포함하지 않는다. GitHub 업로드나 LMS 제출은 실제 수행했을 때만 완료로 기록한다.
