# 14주차 실습·검증 기록

실습일·최종 확인일: 2026-11-17 (한국 시간)

## 구현 결과

- **공감 다이어리:** 일기와 선택 기분을 분석해 감정·공감 메시지를 표시한다. 브라우저 기록 저장·조회·확인 후 삭제를 지원한다. 줄노트·키윗새 엽서·우표와 마루부리로 디자인했다.
- **PDF 요약:** PDF 텍스트를 추출해 일반·간단 요약을 제공한다. 크림·브라운 색상과 마루부리를 유지하며 왼쪽 문서 설정·오른쪽 요약 결과의 업무용 화면으로 구성했다.
- **공통:** 학교 FactChat을 사용한다. 키는 현재 페이지 메모리에만 두고, 전송 동의와 입력·AI 응답 검증을 적용한다. 사용자 입력·AI 응답은 HTML로 해석하지 않는다.
- **교재 대응:** OpenRouter는 FactChat으로 대체했다. HTML에 비밀 키를 넣지 않기 위해 로컬 Python 서버를 함께 사용한다.

## 자동 검사

Python 3.12·pypdf 7.1.0과 기존 Study-04 가상환경에서 실행했다.

| 검사 | 결과와 범위 |
| --- | --- |
| `python -m unittest discover -v` | **12개 통과, 0.032초** |
| AI 처리 | 키·모델·일기·선택 기분 검증, 정상/잘린/비정상 응답과 통신 실패를 모의 검사 |
| PDF 추출 | 생성한 실제 테스트 PDF로 추출, 일반/간단 모드 구분, 10MB·100쪽·60,000자 제한, 암호화·손상·빈 문서 거부 확인 |
| 서버 | 동의·Host·Origin·입력 형식·본문 크기·정적 파일 허용 목록·예외 원문 비노출 검사 |
| `node --check app.js` | 통과 |
| `node test_frontend.cjs` | 기록·선택 기분 저장, 키 미저장, 안전한 텍스트 표시, 손상/저장 실패/삭제 취소 시 데이터 보존, 이전 기록 호환 검사 통과 |
| Python 문법·의존성 | compileall 통과, pip check 충돌 없음 |

손상 PDF 테스트에서 pypdf의 일반 진단 메시지 `EOF marker not found`가 출력되며, 해당 오류는 사용자 안내로 처리한다.

## 실제 브라우저·로컬 서버 검사

- Chrome **1440px·768px·390px**에서 두 화면 배치·폰트·가로 넘침을 확인했다. 마루부리 Regular·SemiBold 모두 로딩됨.
- 다이어리 날짜는 한국 시간으로 표시되고 기분 선택이 동작한다.
- PDF 화면은 실제 브라우저의 테스트용 File 객체와 **모의 API**로 두 요약 모드의 요청·인코딩·결과 표시, 통신 실패 시 기존 결과 보존을 확인했다.
- 실행 서버의 HTML·CSS·JS 제공 성공, 미동의 분석 400·비공개 파일 접근 404를 확인했다.
- 사용자 보유 14번 교재의 **36쪽·5,241자**를 로컬에서 추출했다. 외부 전송은 하지 않았다.
- `screenshots/`에는 최종 다이어리·PDF 화면의 데스크톱/모바일 캡처를 보관했다. 개인정보나 API 키를 입력하지 않은 화면이다.

## 확인하지 않은 범위

- 실제 학교 API로 감정 분석·PDF 요약을 생성하는 검사는 수행하지 않았다. 모의 검사를 실제 API 성공으로 기록하지 않는다.
- 새 가상환경 설치, Windows·Safari 실행, 모든 종류의 PDF와 모델, 운영 서비스 부하는 검사하지 않았다.
- GitHub 업로드는 코드 보관이며 LMS 과제 제출·출석·이수 완료를 의미하지 않는다.
