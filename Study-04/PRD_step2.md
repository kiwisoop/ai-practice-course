# 2단계: 인식한 재료로 레시피 생성

## 목표
1단계에서 얻은 재료를 사용자가 수정하고 요리 조건에 맞는 레시피를 생성한다.
교재 17~22쪽의 실습 흐름을 따른다.

## 구현 범위
- 인식한 재료를 편집·추가·삭제할 수 있다.
- 요리 종류와 난이도를 선택한다.
- 빈 재료 목록으로는 API를 호출하지 않는다.
- [레시피 생성]을 누르면 텍스트 생성 API를 호출한다.
- 요리명, 필요한 재료와 분량, 추가로 필요한 재료, 조리 순서, 예상 시간을 표시한다.
- 생성된 레시피를 제목으로 검색하고, 선택한 요리 종류·난이도로 필터링한다.
- 재료나 조건을 바꾸면 기존 결과가 이전 조건으로 생성되었다는 점을 구분한다.
- 실패 시 기존의 정상 결과를 보존하고 재시도 방법을 안내한다.
- 사용자에게 AI 제안임을 알리고, 알레르기와 충분한 가열 여부를 직접 확인하도록 안내한다.

## API 연동
- 교재 기준: OpenRouter, `deepseek/deepseek-chat-v3.1:free`.
- 현재 제공 여부를 확인한다. 사용할 수 없으면 대체 모델을 사용자와 정하고 유료 전환은 자동으로 하지 않는다.
- 1단계에서 확정한 API 인증 방식을 재사용하되 이미지 분석과 텍스트 생성 호출을 구분한다.
- 구현은 학교용 FactChat 모델 목록에서 사용자가 텍스트 모델을 직접 선택하는 방식으로 조정했다. DeepSeek가 제공되면 선택할 수 있으며 Claude도 사용할 수 있다.
- 키와 원본 사진은 레시피 데이터에 포함하지 않는다.

## 완료 기준
1. 사진 인식 → 재료 수정 → 조건 선택 → 레시피 생성이 연결된다.
2. 재료와 조리 단계가 읽기 쉽게 표시된다.
3. 생성 중 중복 클릭을 막고, 빈 입력·API 오류·빈 응답을 처리한다.
4. 검색·필터가 생성된 레시피에 적용된다.
