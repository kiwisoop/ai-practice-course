## 참조에서 확인되지 않는 부분과 유지한 차이

- PDF는 화면의 일부를 캡처한 자료다. 스크린샷 밖의 세부 화면과 소스 코드는 제공되지 않았다. 프로필·추천의 세부 내용과 회원가입 입력 항목은 확인된 공통 스타일로 구성했다.
- 브라우저 테두리와 교재에서 표시한 빨간 강조 박스는 앱 UI에 포함하지 않았다. 화면 폭과 Streamlit 버전에 따라 글꼴·아이콘·간격의 미세 차이가 있다.
- 원래 교재의 OpenRouter 대신 사용자가 확인한 학교 FactChat API를 유지했다. 키와 모델 선택·전송 동의는 사이드바 설정에 모았다.
- 교재 스크린샷의 예시 숫자와 요리 결과는 복사하지 않고 실제 사용자 데이터와 AI 응답을 표시한다. 기존 저장 데이터는 보존한다.
- 매칭 점수는 재료 보유 비율이고 칼로리는 AI의 추정값이다. 모델이 제공하지 않은 칼로리는 수치를 만들어 표시하지 않는다.
- 회원가입·로그인은 로컬 실습용이며, 공개 데모 계정은 개인정보를 보관하는 계정이 아니다.

브라우저 확인 이미지는 `screenshots/`에 저장한다. 실제 유료 모델 호출 없이 사진 업로드와 화면 이동을 확인했다.
