# 1단계: 냉장고 사진에서 재료 인식

## 목표
냉장고 사진을 업로드하고 이미지 인식 API가 찾은 식재료를 한국어로 확인한다.
교재 5, 9~16쪽을 바탕으로 하는 로컬 실습이다.

## 구현 범위
- Python과 Streamlit으로 한국어 화면을 만든다.
- JPG, PNG 사진을 업로드하고 미리보기를 제공한다.
- 업로드한 파일의 실제 이미지 형식과 크기를 검증한다.
- API 키는 비밀번호 입력란이나 환경 변수로 받고 코드·문서·로그에 저장하지 않는다.
- 사진을 외부 AI 서비스로 전송한다는 안내 후, 사용자가 [재료 인식 시작]을 누를 때만 요청한다.
- 결과에는 눈으로 확인되는 재료와 불확실한 재료를 구분한다. 사진만으로 신선도나 섭취 안전성을 단정하지 않는다.
- 잘못된 키, 요청 제한, 연결 실패, 빈 결과를 한국어로 안내한다.
- 새 사진을 선택하면 이전 사진의 분석 결과를 초기화한다.

## API 연동
- 교재 기준: OpenRouter, `google/gemma-3-27b-it:free`.
- 해당 모델의 현재 제공 여부와 이미지 입력 지원을 확인한 뒤 사용한다.
- 모델이 제공되지 않으면 오류를 안내하고, 유료 모델로 자동 전환하지 않는다.
- 이번 실습은 사용자가 사용하는 학교용 FactChat으로 조정한다. 학교 공식 문서의 Gateway 주소 `https://api.baze.co/v1/gateway`와 Bearer 인증을 사용한다.
- `/models/?type=llm`에서 계정에 허용된 Claude 모델을 조회하고 사용자가 직접 선택한다. 다른 모델로 자동 전환하지 않는다.
- FactChat 호출은 교재의 OpenRouter 무료 모델과 달리 계정 크레딧을 차감할 수 있음을 안내한다.
- 채팅 서비스에서 Claude를 사용할 수 있다는 사실만으로 Anthropic API 키를 보유한 것으로 간주하지 않는다.

## 완료 기준
1. 로컬 화면에서 사진을 선택하고 미리보기를 볼 수 있다.
2. 키가 없으면 외부 요청 없이 키 준비 방법을 안내한다.
3. 정상 응답은 재료 목록으로 표시하고 오류 응답은 앱이 종료되지 않도록 처리한다.
4. 실제 사진 분석은 사용자가 앱에 새 키를 직접 입력한 후 확인한다.
