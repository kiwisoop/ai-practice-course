# 3단계: 사용자 프로필과 레시피 저장

## 목표
로컬 실습용 사용자 프로필로 로그인하고 생성한 레시피를 저장·조회한다.
교재 23~30쪽을 바탕으로 한다.

## 구현 범위
- 실제 개인정보 없이 사용할 수 있는 데모 계정을 제공한다. 데모 로그인은 운영 서비스용 인증이 아님을 화면에 표시한다.
- 로그인·로그아웃과 사용자 이름 표시를 제공한다.
- 사용자별 요리 취향을 프로필에 저장하고 레시피 생성 조건에 반영한다.
- 생성한 레시피 옆의 [저장] 버튼으로 해당 사용자의 보관함에 저장한다.
- Python 표준 라이브러리 SQLite를 사용하고 SQL 값은 매개변수로 전달한다.
- 저장한 레시피를 [나의 레시피]에서 조회하고 폴더로 분류할 수 있다.
- 같은 사용자의 같은 레시피는 중복 저장을 방지한다.
- 삭제 시 대상을 명시하고 확인을 받는다.
- 저장한 레시피 수, 요리 완료로 표시한 횟수, 자주 사용한 재료를 대시보드에 표시한다.
- 모든 조회·변경은 로그인 사용자의 소유권을 확인한다. 로그아웃 시 이전 사용자의 화면 상태를 초기화한다.
- API 키와 원본 사진은 데이터베이스에 저장하지 않는다.

## 완료 기준
1. 로그인 → 레시피 생성 → 저장 → 나의 레시피 조회를 수행할 수 있다.
2. 서버를 재시작해도 SQLite에 저장한 레시피가 남는다.
3. 서로 다른 데모 사용자의 저장 목록이 섞이지 않는다.
4. 중복 저장, 취소한 삭제, 저장 실패 시 데이터가 보존된다.
5. 실제 데이터와 대시보드의 집계가 일치한다.

## 범위 밖
인터넷 배포·운영용 회원가입·비밀번호 재설정·외부 소셜 공유는 이 로컬 실습에 포함하지 않는다. 필요하면 별도 요구사항으로 정한다.
