## 실제 학교 API 검사

공식 주소 `https://api.baze.co/v1/gateway`와 테스트 모델 `claude-haiku-4-5-20251001`을 사용했다.

1. 유효한 테스트 키의 인증과 모델 목록 조회: 성공.
2. `fridge-sample.png`의 실제 식재료 인식: 성공.
3. 인식 결과를 사용한 실제 레시피 생성: **3개 생성 성공**. 요청 조건은 한식·쉬움·최대 45분·2인분·저염식·견과류 제외였다. 응답의 조리 시간은 15분·20분·30분이었고, 인분과 응답 구조를 검증했다.
4. 실제 생성한 레시피의 임시 SQLite 저장·DB 재연결 후 조회·다른 사용자와 분리·평점·요리 횟수 집계: 성공.

실제 호출은 인증이 확인된 테스트 키로 수행했다. 키는 코드·문서·GitHub에 포함하지 않았다. 실제 호출로 생성한 데이터는 임시 DB에서만 검사하고 정리했으며 기존 사용자 DB는 수정하지 않았다.

실제 API 검사는 위 모델과 샘플 사진 1개를 사용한 연동 검사다. 모든 모델·모든 사진의 인식 정확도, 음식의 안전성·영양 수치, 운영 환경의 다중 사용자 부하나 클라우드 배포까지 검증했다는 의미는 아니다. 데모 계정은 공개 실습용이다.
