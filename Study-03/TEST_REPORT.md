# 2026-11-10 보완 검사

기본 50문제는 유지하고 확장 1문제를 추가했다. 사실 확인 결과는 SOURCE_REVIEW.md, 동작 검사는 아래와 같이 구분한다.

## 자동 검사

- `node ../Study-02/check.js`: 키워드 추천, 대소문자, 긴 키워드 우선, 불일치, 잘못된 설정.
- `node check.js`: 기존 50/0/25점 채점·순위·중복 답변/저장·잘못된 기록·저장 실패 보존 검사를 유지했다. JSON 원본과 생성 데이터가 일치한다.
- `node check-extensions.js`: 4개 모드의 문제 수·완료·점수·분리 저장, 15초 경계와 중복 만료 방지, 힌트 8점과 중복 사용 차단, 날짜별 선택, 보고서 검증·등급·빈 기록·HTML/CSV 안전 처리.
- `python3 check_tools.py`: 잘못된 문제·중복 거절, 일일 선택의 브라우저/CLI 일치, 원자적 JSON 출력, 추가 후 검사 실패 시 확장 데이터·브라우저 데이터 복구.
- 실제 확장 추가→데이터 생성→게임 검사와 일일 JSON 생성을 실행했다. 중복 후보는 저장 전 거절한다.

## 브라우저 확인

로컬 테스트 서버의 별도 포트를 사용해 기존 사이트의 브라우저 데이터를 건드리지 않았다. ChatGPT 내장 브라우저에서 확인했다.

- 할 일: `회사 스케줄`의 업무 추천, 직접 선택한 개인 유지, 저장된 항목의 업무 재분류, 긴 키워드 사용자 설정을 저장한 뒤 새로고침하여 개인 추천 유지.
- 스피드: 15초 표시, 힌트 후 오답 보기 2개 비활성화, 시간 초과 0점·보기 잠금·해설·다음 문제 활성화.
- 분야별 연습: 컴퓨터공학 10문제 완료, 실제 선택 결과 2/10점, 이름 저장·중복 저장 버튼 잠금·JSON 다운로드.
- 보고서: 내보낸 JSON을 가져와 연습 모드의 기록 1개·20%·F·분야별 점수 확인, CSV/HTML 다운로드. 잘못된 JSON을 가져오면 오류 안내와 기존 1개 기록이 유지됨을 확인.
- 일일 퀴즈: 10문제 완료와 모드 선택 복귀.
- 320px 뷰포트의 시작 화면과 교사 화면에서 문서 전체의 가로 넘침이 없음을 확인했다. 표는 내부 가로 스크롤을 제공한다. 시작 화면 스크린샷을 검토했다.
- 할 일·퀴즈·교사 화면의 브라우저 JavaScript 오류 로그가 없었다.
