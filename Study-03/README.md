# Study-03 — 상식 한 바퀴

국립목포대학교 인공지능활용실습의 「할루시네이션 없는 AI 콘텐츠 만들기」 교재를 바탕으로 만든 3차 과제이다. 교재의 한국사·과학·지리·일반상식 40문제에 사용자 요청으로 컴퓨터공학 10문제를 추가했다.

한국사·과학·지리·일반상식·컴퓨터공학 각 10문제, 총 50문제를 푸는 4지선다 퀴즈이다. 답변하면 정답·해설·출처가 표시되고, 마지막에 총점과 분야별 점수를 확인한다.

완료 화면에서 이름을 입력해 이번 결과를 선택적으로 저장한다. 높은 점수순으로 표시하며 동점은 공동 순위다. 동점 안에서는 완료 시각이 빠른 기록이 먼저 나온다. 이름·총점·분야별 점수·완료 시각은 현재 브라우저에만 저장되며, 브라우저 데이터를 지우면 사라질 수 있다. 저장하지 않아도 게임과 다시 도전을 이용할 수 있다.

## 실행

이 폴더의 `index.html`을 브라우저로 연다. 설치나 서버, API 키가 필요 없다. 출처 웹페이지를 방문할 때는 인터넷 연결이 필요하다.

저장소를 내려받거나 ZIP 압축을 풀고 `Study-03/index.html`을 더블 클릭하면 된다. Git으로 내려받는 경우:

```sh
git clone https://github.com/kiwisoop/ai-practice-course.git
cd ai-practice-course/Study-03
```

macOS에서는 `open index.html`, Windows에서는 `start index.html`, Linux에서는 `xdg-open index.html`로 실행할 수 있다. 이 명령 안내가 모든 운영체제에서 동작 검사를 마쳤다는 뜻은 아니다.

## 사용 방법

1. ‘퀴즈 시작’을 누른다.
2. 보기 하나를 선택하고 정답·해설·출처를 확인한다.
3. ‘다음 문제’로 총 50문제를 진행한다.
4. 총점과 분야별 점수를 확인한다. 원하는 경우 이름을 입력하고 ‘이번 결과 저장’을 누른다.
5. 순위를 확인하거나 ‘다시 도전’으로 새 게임을 시작한다.

## AI를 사용한 방법

Codex와 요구사항을 정리하고, 문제은행의 정답·해설을 출처와 대조한 뒤 기본 게임과 순위 저장을 단계별로 구현했다. 사용자가 기본 게임을 직접 실행해 정상 동작을 확인했고, 자동 검사와 별도 Chrome 검사 결과를 아래에 기록했다. 교재의 Claude `/memory`, `/clear`를 사용한 것처럼 기록하지 않고, 작업 규칙과 검증 기준을 `AGENTS.md`에 남겼다.

## 파일

- `PRD.md`: 합의한 요구사항
- `PROMPTS.md`: 단계별 구현·검증 프롬프트
- `AGENTS.md`: 작업 규칙
- `questions.json`: 문제·정답·해설·출처 원본
- `QUESTIONS.md`: 읽기용 문제은행과 자료 확인 기록
- `index.html`, `styles.css`, `quiz.js`: 게임 화면과 동작
- `questions-data.js`: 브라우저에서 사용할 생성 데이터
- `build_data.py`, `check.js`: 데이터 생성과 동작 검사

문제 원본을 수정했다면 이 폴더에서 실행한다.

```sh
python3 build_data.py
node check.js
node --check quiz.js
```

`QUESTIONS.md`의 해당 문제도 함께 갱신한다.

## 완료 범위와 검증

2026-10-01 기준 PROMPTS.md의 1단계 기본 게임을 구현했다.

- 데이터·로직 검사 통과: 50문제, 분야별 10문제, 고정 순서, 원본과 생성 데이터 일치, 전부 정답/오답/절반 정답의 50/0/25점, 중복·잘못된 답변 차단, 미응답 건너뛰기 차단, 완료 후 답변 차단, 다시 시작 초기화.
- 설치된 Chrome 154에서 `file://`로 실제 화면 검사 통과: 전부 정답과 전부 오답 각각 50문제 진행, 분야 전환, 해설·출처 링크 주소, 선택 후 보기 비활성화, 진행 표시, 총점·분야별 점수, 다시 시작.
- 키보드로 시작·답변·다음 문제 이동을 확인했다. 모바일 크기 390px·320px에서 가로 넘침이 없음을 확인하고 화면 이미지를 검토했다. 페이지 JavaScript 오류는 발생하지 않았다.
- 첫 자동 검사에서는 Chrome이 페이지를 열기 전 macOS 앱 등록 단계에서 종료됐다. 실행 권한을 갖춘 별도 검사에서는 위 흐름이 정상 완료됐다. Chrome 자체의 일반적인 충돌 문제가 해결되었다는 의미는 아니다.

출처 내용 대조는 문제은행 작성 과정에서 수행했다. 이번 화면 검사에서는 링크 주소를 확인했으며 모든 외부 웹페이지를 다시 방문하지 않았다. 사람·독립 검토자의 재검토, 실제 모바일 기기·스크린리더 검사는 수행하지 않았다.

## 2단계 — 기록 저장 검증

2026-10-05에 2단계 이름 입력과 브라우저 내 순위 저장을 구현했다.

- `node check.js`와 `node --check quiz.js` 통과. 기존 채점 검사에 이름 공백 제거·1~20자 제한, 완료 후 한 번만 저장, 공동 순위 1·1·3위, 동점 시각 순서, 다시 시작 후 기록 유지, 잘못된 JSON·점수·시각·분야별 점수, 읽기 차단·저장 실패 후 재시도 검사를 추가했다.
- 임시 Chrome 프로필에서 `file://` 화면 검사 통과: 저장·새로고침 복원·공동 순위·완료 시각 순서·중복 저장 방지·공백 이름·21자 이름·HTML 형태 이름의 안전한 표시를 확인했다.
- 잘못된 JSON·잘못된 기록이 보존되고, 저장 차단·용량 부족을 모의한 상황에서 오류 안내와 게임 진행이 유지되는 것을 확인했다. 키보드 시작·이름 입력 후 Enter 저장·다시 도전과 320px 순위 화면을 확인했다. 페이지 JavaScript 오류는 없었다. 저장 차단과 용량 부족은 실제 브라우저 설정 변경 대신 테스트 중 오류를 발생시켜 확인했다.

## 남은 작업과 제한

3단계의 최종 출처 재검토는 아직 완료하지 않았다. 실행 파일·제작 문서·검증 기록을 저장소 등록용으로 정리했으며, GitHub 등록은 수업 제출 시스템에 제출했다는 의미가 아니다. 공식 제출 기한·양식과 Claude 사용의 필수 여부는 별도 과제 공지로 확인해야 한다.

서버·계정·온라인 순위·기기 간 동기화는 제공하지 않는다. 브라우저나 파일 위치를 바꾸면 저장 기록이 공유되지 않을 수 있다. 모든 문제를 독립 출처 두 개로 검증한 것은 아니며, 자료 확인 방식과 한계는 `QUESTIONS.md`와 `questions.json`에 기록했다.
