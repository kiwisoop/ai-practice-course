# 배경음악 선택 — 2026-11-19

- 사용자 승인 후 Wikimedia Commons에서 CC BY 곡 4개(약 16MB)를 받아 `assets/music/`에 넣었다. 파일 크기·길이가 Commons 정보와 일치함을 ffprobe로 확인했다. 감정 분석 없이 사용자가 곡을 고르고(기본: 경쾌한 어쿠스틱), 3년 쇼츠는 마무리 장면에서 다른 밝은 곡으로 1.5초 겹쳐 바뀐다.
- 곡마다 음량 차이를 loudnorm으로 맞췄다(실측 -17.4 / -18.3 LUFS). CC BY 출처는 쇼츠 창·3년 버튼 아래·보관함·예시 페이지와 MP4 comment 메타데이터에 표시한다. 3년 쇼츠의 곡 선택 검증은 유료 이야기 호출보다 먼저 한다.
- 검증: Python 59개 통과(신규: 곡 파일·출처 존재, 마무리 곡이 항상 다른 곡, 곡 전환 오디오 그래프, 잘못된 곡 선택이 유료 호출 전에 거부됨, 설정의 곡 목록·영상 메타데이터, 곡 전환 실제 MP4 7.5초·오디오·출처 메타데이터). 기존 테스트 1건은 export_video 인자에 music이 추가된 만큼 기대값을 갱신했다. node 검사 6묶음 통과(신규: 곡 선택·출처 표기).
- 예시 영상 재렌더링: 하루 24초(경쾌한 어쿠스틱), 3년 34.5초(따뜻한 어쿠스틱 → 마무리 희망찬 우쿨렐레). 곡의 실제 분위기는 설명·제목 기준으로 골랐고 사람이 들어 보는 확인은 사용자 몫으로 남는다.

- 쇼츠 예시 페이지를 새 일기와 v2 연출 영상(하루 24초·3년 34.5초, 720×1280 H.264/AAC, 전체 디코딩 통과)으로 교체했다. API 미사용.

# v2 검증 기록 — 2026-11-19

ECC `feature-dev` 흐름(요구사항 → 코드 탐색 → 질문 → 설계 승인 → 구현 → `code-reviewer` 리뷰)으로 만들었다. 유료 API는 호출하지 않았고, 모의 응답·임시 DB와 AI 호출을 막은 임시 서버로만 검증했다. v1 폴더와 실제 사용자 DB는 수정하지 않았다.

## 자동 테스트

| 검사 | 결과 |
|---|---|
| `python3 -m unittest -q` | 50개 통과 (v1 46개 + 신규 `test_v2.py` 4개, 3년 영상 테스트는 카드 구성에 맞게 수정) |
| `node --check static/app.js` | 통과 |
| `node test_frontend.cjs` | 5묶음 통과 (신규: 오늘의 질문·지난 기록 안내) |

신규 테스트가 확인하는 것:
- FFmpeg 탐지 순서(환경변수 → ffmpeg-full → PATH), 자막 미지원 빌드 건너뛰기, 아무것도 없을 때의 대체값
- 카드 검증: 카드는 장면 8개 제한에 포함되지 않음, 최대 4개, 1~4초·1/24초 단위, 빈 제목·줄바꿈·과도한 길이 거부
- 카드 포함 실제 MP4: 8.0초, 720×1280, 오디오 트랙, 전체 디코딩
- 3년 영상 구성: 제목 카드 → (연도 카드 → 시작 장면 → 마무리 장면) × 3, 보관 길이 = 장면 24초 + 2.5초 + 1.5초 × 3
- 오늘의 질문: 윤년 기준 날짜 순번 고정(3월 1일 = 60, 2월 29일 = 59), 매년 같은 질문
- 지난 기록 안내: 최근 해가 비고 지난 해 기록이 있을 때만 표시, 개수·점수 표시 없음, 미래 날짜·다른 날짜 항목 제외

## 실제 실행 확인 (임시 서버, AI 차단)

- 3년 쇼츠 실제 렌더링: 31초, 720×1280, H.264/AAC, 전체 디코딩 통과. 제목 카드와 연도 카드("2024" → 그해 장면)를 프레임으로 확인.
