# 인공지능활용실습 3주차 과제 제출 설명

## 1. 과제명

MNIST 데이터세트를 활용한 손글씨 숫자 인식 프로그램

## 2. 개발 목적

사용자가 화면에 직접 그린 0부터 9까지의 숫자를 인공지능 모델이 판별하도록 구현하는 것이 목적이다. 동일한 인식 기능을 데스크톱 프로그램과 웹 프로그램에서 사용할 수 있도록 구성하였다.

## 3. 사용 기술

- Python과 TensorFlow/Keras
- MNIST 손글씨 숫자 데이터세트
- Tkinter 데스크톱 GUI
- HTML Canvas와 JavaScript 웹 인터페이스
- Pillow와 NumPy를 이용한 이미지 전처리
- Codex를 이용한 코드 생성, 파일 구성 및 검증

## 4. 구현 내용

MNIST 이미지로 합성곱 신경망을 3회 학습하고 학습된 모델을 `mnist_model.keras`로 저장한다. 사용자가 그린 그림에서는 숫자가 있는 영역을 찾아 잘라낸 다음, 긴 변을 20픽셀로 축소하고 28×28 크기의 검은 이미지 중앙에 배치한다. 픽셀값을 0부터 1 사이로 정규화한 뒤 모델에 입력하여 가장 가능성이 높은 숫자와 신뢰도를 출력한다.

데스크톱 버전은 Tkinter의 검은 캔버스에 흰색 선으로 숫자를 그리며, Clear 버튼으로 그림을 지우고 Recognize 버튼으로 결과를 확인한다. 웹 버전은 브라우저의 Canvas에 숫자를 그리고 로컬 Python 서버의 `/predict` 경로로 이미지를 전송하여 같은 모델의 결과를 표시한다.

## 5. 프로젝트 구조의 특징

루트의 `AGENTS.md`에는 프로젝트 공통 목표와 실행·검사 방법을 기록하였다. `desktop_version`과 `web_version`에는 각각의 구현 규칙을 담은 별도 `AGENTS.md`를 배치했다. 두 프로그램은 루트의 `mnist_model.py`를 공유하므로 학습 코드와 이미지 처리 코드가 중복되지 않는다.

## 6. 실행 결과 확인 방법

데스크톱 버전은 `desktop_version/run_desktop.bat`, 웹 버전은 `web_version/run_web.bat`을 더블 클릭하여 실행한다. 숫자를 그리지 않은 상태에서 인식을 요청하면 안내 메시지를 표시하며, 숫자를 그린 경우 예측 숫자와 백분율 신뢰도를 출력한다.

## 7. 느낀 점

같은 MNIST 모델이라도 실제 사용자가 그린 숫자를 인식하려면 학습 이미지와 비슷하게 크기를 조절하고 중앙에 배치하는 전처리 과정이 중요하다는 것을 확인하였다. 또한 공통 모델 코드를 공유하면서 인터페이스만 데스크톱과 웹으로 분리하면 중복을 줄이고 유지보수하기 쉽다는 점을 배웠다.
