# Kiwibird

Kiwibird는 해야 할 일을 둥지에 하나씩 모아 가는 개인용 할 일 관리 앱입니다. 할 일이 생기면 둥지에 알이 나타나고, 오늘의 일을 모두 끝내면 알 대신 키위새를 만날 수 있습니다.

국립목포대학교 **인공지능활용실습 4주차 과제**로 만들었습니다. AI의 도움을 받아 코드를 작성했지만, 기능을 한꺼번에 만들지 않고 요구사항 정리부터 테스트와 수정까지 단계별로 직접 확인하며 완성했습니다.

## 주요 기능

- 할 일 추가, 수정, 완료, 삭제
- 업무, 과제, 공부, 취미, 개발, 개인 카테고리
- 마감일과 중요도 설정
- 검색, 상태·카테고리 필터와 정렬
- 전체 및 카테고리별 완료율 대시보드
- 빈 둥지 → 알이 있는 둥지 → 키위새가 있는 둥지 변화
- 우선순위에 맞는 할 일을 추천하는 `Kiwibird Focus`
- 15분, 25분, 45분 빠른 선택과 5~120분 직접 설정 타이머
- 라이트·다크 모드
- 브라우저 자동 저장
- JSON 파일 내보내기와 가져오기
- 화면 크기에 맞게 변하는 반응형 디자인

## 바로 실행하기

별도의 패키지나 회원가입은 필요하지 않습니다. 이 저장소를 내려받은 뒤 `Study-02/index.html`을 브라우저에서 열면 됩니다.

### Windows

1. [Git for Windows](https://git-scm.com/download/win)를 설치합니다.
2. PowerShell 또는 명령 프롬프트에서 아래 명령을 실행합니다.

```powershell
git clone https://github.com/kiwisoop/ai-practice-course.git
cd ai-practice-course\Study-02
start index.html
```

압축 파일로 내려받았다면 압축을 풀고 `Study-02` 폴더의 `index.html`을 더블 클릭해도 됩니다.

### macOS

터미널에서 아래 명령을 실행합니다.

```bash
git clone https://github.com/kiwisoop/ai-practice-course.git
cd ai-practice-course/Study-02
open index.html
```

Finder에서 `index.html`을 Safari나 Chrome으로 열어도 됩니다.

### Ubuntu Linux

Git이 없다면 먼저 설치합니다.

```bash
sudo apt update
sudo apt install git
git clone https://github.com/kiwisoop/ai-practice-course.git
cd ai-practice-course/Study-02
xdg-open index.html
```

Firefox나 Chrome에서 `index.html`을 직접 열어도 됩니다.

## 로컬 서버로 실행하기

직접 열기가 가장 간단하지만, 브라우저의 파일 접근 제한 때문에 문제가 생기면 Python 기본 서버를 사용할 수 있습니다.

```bash
cd Study-02
python3 -m http.server 8765
```

Windows에서 `python3`가 인식되지 않으면 다음 명령을 사용합니다.

```powershell
py -m http.server 8765
```

그다음 브라우저에서 <http://127.0.0.1:8765>를 엽니다. 서버를 끝낼 때는 터미널에서 `Ctrl+C`를 누릅니다.

## 사용 방법

1. 할 일 내용과 카테고리를 입력합니다.
2. 필요하면 마감일과 중요도를 정한 뒤 `할 일 추가`를 누릅니다.
3. 끝낸 일은 체크박스로 완료합니다.
4. 목록이 많아지면 검색, 상태, 카테고리와 정렬 조건을 함께 사용합니다.
5. `지금 집중할 일`에서 추천 항목과 집중 시간을 확인하고 타이머를 시작합니다.
6. 다른 브라우저나 컴퓨터로 옮길 때는 `JSON 내보내기`로 백업하고 `JSON 가져오기`로 복원합니다.

할 일과 설정은 현재 브라우저의 `localStorage`에 저장됩니다. 브라우저 데이터를 삭제하면 함께 사라질 수 있으므로 중요한 목록은 JSON으로 백업하는 편이 안전합니다.

## 단계별 제작 과정

### 1단계 — 기본 할 일 흐름

먼저 입력, 추가, 완료와 삭제만 만들었습니다. 공백만 입력한 항목은 거부하고, 사용자 입력을 HTML이 아닌 일반 글자로 표시해 안전하게 처리했습니다.

### 2단계 — 일정 정보 추가

여섯 개 카테고리와 마감일, 중요도를 추가했습니다. 어제·오늘·내일 날짜를 넣어 `기한 지남`, `오늘`, `D-1`이 날짜 차이 없이 표시되는지 확인했습니다.

### 3단계 — 대시보드와 수정

전체·카테고리별 완료율과 수정 기능을 만들었습니다. 처음에는 둥지와 새를 각각 도형 레이어로 표현했지만, 새가 둥지 위에 떠 보이는 문제가 있었습니다. 빈 둥지, 알이 든 둥지, 새가 앉은 둥지를 각각 하나의 합성 이미지로 바꿔 앞쪽 나뭇가지가 알과 새의 몸을 자연스럽게 가리도록 수정했습니다.

### 4단계 — 검색과 집중 기능

검색, 복합 필터, 정렬, 다크 모드와 `Kiwibird Focus`를 추가했습니다. 타이머는 단순히 1초씩 빼지 않고 종료 시각을 기준으로 계산해 브라우저가 잠시 느려져도 오차가 커지지 않게 했습니다. 집중 시간이 끝나도 할 일을 자동 완료하지 않도록 사용자의 선택을 남겨 두었습니다.

### 5단계 — 저장과 백업

목록을 바꿀 때마다 브라우저에 자동 저장하고 새로고침 뒤에도 복원되게 했습니다. JSON 가져오기는 제목, 카테고리, 마감일, 중요도, 완료 상태와 저장 시각을 모두 검사합니다. 잘못된 항목이 하나라도 있으면 기존 목록을 그대로 두고 이유를 안내합니다.

## AI를 사용한 방법

AI에는 한 번에 완성해 달라고 요청하지 않고 `PRD.md`에서 요구사항을 먼저 정한 뒤 `PROMPTS.md`의 다섯 단계로 나누어 작업을 요청했습니다. 각 단계가 끝날 때마다 브라우저에서 직접 동작을 확인하고, 눈으로 보이는 문제와 예상과 다른 동작을 다시 설명해 수정했습니다.

특히 키위새 화면은 “코드가 실행된다”는 결과만 보지 않고 다음 상태를 처음부터 반복해 확인했습니다.

1. 할 일이 없을 때 빈 둥지
2. 미완료 할 일이 있을 때 둥지 안의 알
3. 모든 할 일을 완료했을 때 둥지 안의 키위새
4. 완료를 취소했을 때 다시 알로 복귀
5. 다시 완료했을 때 키위새로 전환

AI가 만든 코드를 그대로 제출하는 것이 아니라, 원하는 결과를 구체적으로 정하고 실행 화면과 상태값을 확인하면서 개선하는 과정에 중점을 두었습니다.

## 확인한 내용

- 빈 내용 입력 거부
- 추가, 수정, 완료, 완료 취소와 삭제
- 카테고리, 마감일과 중요도 표시
- 검색·상태·카테고리·정렬 동시 사용
- 라이트·다크 모드 전환
- 할 일 개수와 완료율 즉시 갱신
- 빈 둥지, 알, 키위새 이미지 전환과 둥지 앞뒤 관계
- 새로고침 뒤 목록과 설정 복원
- JSON 백업 구조 검사와 기존 데이터 보호
- 데스크톱 및 모바일 너비 표시
- JavaScript 문법과 브라우저 오류 기록

## 데이터와 제한 사항

- 서버와 계정이 없는 개인용 앱이므로 여러 기기 사이에 자동 동기화되지 않습니다.
- 브라우저 저장 공간을 비우면 저장된 목록도 삭제됩니다.
- 타이머가 끝났다는 운영체제 알림이나 푸시 알림은 보내지 않습니다.
- 반복 일정, 공동 작업과 사용자 정의 카테고리는 이번 과제 범위에서 제외했습니다.
- API 키, 비밀번호와 개인정보를 저장하거나 외부로 전송하지 않습니다.
