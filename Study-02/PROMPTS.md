# Kiwibird 단계별 개발 프롬프트

이 문서는 `PRD.md`의 요구사항을 다섯 단계로 나누어 Codex에 전달하기 위한 작업 지시서이다. 한 번에 한 단계만 실행하고, 확인이 끝난 뒤 다음 단계로 넘어간다.

## 사용 방법

1. `Study-02` 폴더에서 작업을 시작한다.
2. 아래 프롬프트를 Step 1부터 순서대로 하나씩 사용한다.
3. Codex가 작업을 끝내면 해당 단계의 확인 항목을 직접 시험한다.
4. 문제가 있으면 같은 단계에서 수정한 뒤 커밋한다.
5. 이전 단계의 기능을 유지하면서 다음 단계로 진행한다.

## 모든 단계에 적용할 공통 규칙

- 작업 전에 `PRD.md`, `PROMPTS.md`, `AGENTS.md`가 있으면 먼저 읽는다.
- 순수 HTML, CSS, JavaScript만 사용한다.
- 프레임워크, 패키지, 외부 API와 외부 이미지에 의존하지 않는다.
- `index.html`을 직접 열어 실행할 수 있어야 한다.
- 사용자에게 보이는 문구는 자연스러운 한국어로 작성한다.
- 파일명, 변수명, 함수명과 코드 주석은 영어로 작성한다.
- 사용자 입력을 HTML로 실행하지 말고 일반 글자로 안전하게 표시한다.
- 키보드 사용, 포커스 표시, 색상 대비와 모바일 화면을 고려한다.
- 요청한 단계의 기능만 구현하고 다음 단계 기능을 미리 만들지 않는다.
- 기존 기능을 삭제하거나 동작을 바꾸기 전에 영향 범위를 확인한다.
- 작업이 끝나면 변경 파일, 확인 결과, 남은 제한 사항을 짧게 설명한다.
- 새 라이브러리와 불필요한 추상화는 추가하지 않는다.

## Step 1. 기본 구조와 핵심 기능

다음 내용을 Codex에 전달한다.

```text
Study-02 폴더의 PRD.md와 PROMPTS.md를 먼저 읽어 줘.

이번에는 Kiwibird의 Step 1만 구현해 줘. index.html, styles.css, script.js를 만들고 순수 HTML, CSS, JavaScript만 사용해. index.html을 브라우저에서 직접 열어 실행할 수 있어야 해.

구현할 기능:
- 앱 이름 Kiwibird와 문구 "오늘 할 일을 가볍게 정리해요."
- 할 일 내용 입력창
- 추가 버튼과 Enter 키로 할 일 추가
- 체크박스로 완료 상태 변경
- 할 일 한 개 삭제
- 빈 내용과 공백만 있는 내용은 추가하지 않고 한국어 안내 표시
- 할 일이 없을 때 빈 목록 안내 표시
- 초록색과 크림색을 중심으로 한 기본 키위새 테마
- 모바일에서도 사용할 수 있는 기본 반응형 화면

안전과 접근성:
- 사용자 입력은 textContent 등 안전한 방법으로 표시해.
- 입력창에 label 또는 접근 가능한 이름을 제공해.
- 버튼과 체크박스를 키보드로 사용할 수 있게 해.
- 포커스 위치가 눈에 보이게 해.

이번 단계에서는 카테고리, 마감일, 중요도, 대시보드, 수정, 검색, 다크 모드, Focus 타이머, localStorage와 JSON 기능을 만들지 마.

완료 후 다음을 직접 확인해 줘:
1. 정상 내용이 추가되는지
2. 빈 내용이 거부되는지
3. 완료 체크가 바뀌는지
4. 선택한 항목만 삭제되는지
5. 모바일 너비에서 가로 스크롤이 생기지 않는지

확인 결과와 변경한 파일을 알려 주고 여기서 멈춰 줘.
```

직접 확인할 내용:

- `과제 제출하기`를 입력해 추가한다.
- 공백만 입력했을 때 항목이 생기지 않는지 확인한다.
- 완료 체크와 삭제 버튼을 시험한다.
- 브라우저 폭을 줄여 화면이 깨지지 않는지 확인한다.

권장 커밋 메시지:

```text
Build Kiwibird basic task flow
```

## Step 2. 카테고리, 마감일과 중요도

다음 내용을 Codex에 전달한다.

```text
Study-02의 PRD.md, PROMPTS.md와 현재 코드를 먼저 읽어 줘. Step 1 기능을 유지하면서 Step 2만 구현해 줘.

구현할 기능:
- 업무, 과제, 공부, 취미, 개발, 개인의 6개 카테고리
- 할 일 추가 시 카테고리 선택
- 카테고리마다 이름과 서로 구분되는 색상 표시
- 전체 및 카테고리별 필터
- 선택 사항인 마감일 입력
- 낮음, 보통, 높음의 중요도 선택과 보통 기본값
- 마감일을 D-숫자, 오늘, 기한 지남으로 표시
- 완료한 항목에서는 기한 초과 경고 제외
- 모바일에서 입력 항목이 자연스럽게 줄바꿈되도록 개선

구현 기준:
- 기본 HTML의 select와 input type="date"를 우선 사용해.
- 날짜 비교는 사용자의 현지 날짜를 기준으로 하고 시간 차이 때문에 하루가 어긋나지 않게 해.
- 색상만으로 카테고리와 중요도를 구분하지 말고 글자도 함께 표시해.
- Step 1의 추가, 완료, 삭제 기능을 그대로 유지해.

이번 단계에서는 대시보드, 할 일 수정, 둥지, 검색, 상태 필터, 정렬, 다크 모드, Focus 타이머, localStorage와 JSON 기능을 만들지 마.

완료 후 다음을 확인해 줘:
1. 여섯 카테고리로 각각 할 일을 추가할 수 있는지
2. 카테고리 필터가 정확한 항목만 표시하는지
3. 미래, 오늘, 과거 마감일 표시가 정확한지
4. 중요도 기본값과 표시가 정확한지
5. 완료한 항목에서 기한 초과 경고가 사라지는지

확인 결과와 변경한 파일을 알려 주고 여기서 멈춰 줘.
```

직접 확인할 내용:

- 여섯 카테고리에 항목을 하나씩 추가한다.
- 어제, 오늘, 내일 날짜를 입력해 표시를 비교한다.
- 완료한 기한 초과 항목에 경고가 남지 않는지 확인한다.

권장 커밋 메시지:

```text
Add task categories deadlines and priorities
```

## Step 3. 대시보드, 수정과 Kiwibird 둥지

다음 내용을 Codex에 전달한다.

```text
Study-02의 PRD.md, PROMPTS.md와 현재 코드를 먼저 읽어 줘. Step 1과 Step 2 기능을 유지하면서 Step 3만 구현해 줘.

구현할 기능:
- 오늘 마감인 할 일 개수
- 남은 일, 완료한 일, 기한이 지난 일 개수
- 전체 완료율과 진행률 막대
- 카테고리별 완료율
- 전체 완료율에 따라 변하는 Kiwibird 둥지
  - 0~24%: 빈 둥지
  - 25~49%: 나뭇잎이 생긴 둥지
  - 50~74%: 알이 있는 둥지
  - 75~99%: 키위새가 나타난 둥지
  - 100%: 완성된 둥지와 "오늘 할 일을 모두 끝냈어요!" 메시지
- 수정 버튼으로 할 일 수정
- 할 일을 더블 클릭해도 같은 수정 기능 실행
- 수정할 때 기존 내용, 카테고리, 마감일과 중요도를 입력 영역에 표시
- 수정 저장과 취소 기능
- Esc 키로 수정 취소

구현 기준:
- 둥지는 외부 이미지 없이 HTML, CSS와 간단한 인라인 SVG만 사용해.
- 할 일이 없을 때 전체 진행률은 0%로 표시하고 계산 오류가 나지 않게 해.
- 수정 버튼과 더블 클릭은 하나의 공통 수정 흐름을 사용해.
- 완료 상태가 바뀌면 모든 개수, 진행률과 둥지가 즉시 갱신되게 해.
- 사용자가 무엇을 수정 중인지 화면에 명확히 표시해.

이번 단계에서는 검색, 상태 필터, 정렬, 다크 모드, 완료 항목 일괄 삭제, Focus 타이머, localStorage와 JSON 기능을 만들지 마.

완료 후 다음을 확인해 줘:
1. 할 일이 없을 때 대시보드가 정상인지
2. 완료율 0%, 25%, 50%, 75%, 100% 구간에서 둥지가 바뀌는지
3. 완료 상태 변경 시 모든 통계가 즉시 갱신되는지
4. 수정 버튼과 더블 클릭이 같은 결과를 내는지
5. 수정 취소 시 기존 데이터가 바뀌지 않는지

확인 결과와 변경한 파일을 알려 주고 여기서 멈춰 줘.
```

직접 확인할 내용:

- 네 개의 할 일을 만들고 하나씩 완료하며 둥지 변화를 확인한다.
- 수정 버튼과 더블 클릭을 각각 사용한다.
- `Esc`를 눌러 수정이 취소되는지 확인한다.

권장 커밋 메시지:

```text
Add dashboard editing and Kiwibird nest
```

## Step 4. 검색, 다크 모드와 Kiwibird Focus

다음 내용을 Codex에 전달한다.

```text
Study-02의 PRD.md, PROMPTS.md와 현재 코드를 먼저 읽어 줘. Step 1부터 Step 3까지의 기능을 유지하면서 Step 4만 구현해 줘.

구현할 기능:
- 라이트 모드와 다크 모드 전환
- 처음에는 운영체제 테마를 따르고 사용자가 선택한 테마는 저장
- 할 일 내용 검색
- 상태 필터: 전체, 진행 중, 완료, 기한 지남
- 기존 카테고리 필터와 함께 사용하는 복합 필터
- 정렬: 마감일순, 중요도순, 최근 등록순
- 모든 검색과 필터 조건 초기화
- 완료한 항목 일괄 삭제와 삭제 전 확인
- / 키로 검색창 이동
- Kiwibird Focus 추천 카드
- 다음 순서로 미완료 할 일 하나 추천
  1. 기한이 지난 일
  2. 오늘 마감인 일
  3. 중요도가 높은 일
  4. 마감일이 가까운 일
  5. 먼저 등록한 일
- 15분, 25분, 45분 빠른 선택
- 5분부터 120분까지 정수 직접 입력, 기본값 25분
- 집중 타이머 시작, 일시정지, 계속하기, 종료
- 실행 중 시간을 변경하거나 종료할 때 확인
- 시간이 끝나면 화면과 브라우저 제목으로 알림
- 시간이 끝나도 할 일을 자동 완료하지 않음
- 오늘 완료한 집중 횟수 표시

구현 기준:
- 검색은 대소문자와 앞뒤 공백의 영향을 최소화해.
- 검색, 상태, 카테고리와 정렬을 동시에 적용할 수 있게 해.
- 타이머는 단순히 1초씩 빼지 말고 실제 종료 시각을 기준으로 남은 시간을 계산해 탭이 잠시 느려져도 크게 어긋나지 않게 해.
- 입력한 집중 시간은 5~120 사이의 정수인지 검사해.
- 추천할 미완료 항목이 없으면 타이머를 시작하지 말고 안내해.
- 다크 모드에서도 글자, 포커스와 카테고리 표시가 충분히 보이게 해.

이번 단계에서는 할 일 목록의 localStorage 저장, JSON 가져오기·내보내기와 오늘의 격언을 만들지 마. 테마와 마지막 집중 시간 설정만 저장해도 돼.

완료 후 다음을 확인해 줘:
1. 복합 필터와 세 정렬 방식이 정확한지
2. 완료 항목 일괄 삭제가 완료 항목만 지우는지
3. 라이트·다크 모드와 저장된 테마가 정상인지
4. 추천 우선순위가 기한과 중요도에 따라 바뀌는지
5. 5 미만, 120 초과, 소수와 빈 집중 시간이 거부되는지
6. 타이머의 시작, 일시정지, 계속하기와 종료가 동작하는지
7. 타이머 종료 후 할 일이 자동 완료되지 않는지

확인 결과와 변경한 파일을 알려 주고 여기서 멈춰 줘.
```

직접 확인할 내용:

- 기한 초과, 오늘 마감, 높은 중요도 항목을 만들어 추천 순서를 확인한다.
- 테스트할 때는 5분을 선택해 시작·일시정지·종료를 확인한다.
- 검색과 여러 필터를 동시에 적용한다.
- 다크 모드에서 모든 문구와 버튼이 보이는지 확인한다.

권장 커밋 메시지:

```text
Add filtering dark mode and Kiwibird Focus
```

## Step 5. 저장, 백업과 최종 완성

다음 내용을 Codex에 전달한다.

```text
Study-02의 PRD.md, PROMPTS.md와 현재 코드를 모두 읽어 줘. Step 1부터 Step 4까지의 기능을 유지하면서 Step 5를 구현하고 과제를 최종 점검해 줘.

구현할 기능:
- 할 일 목록을 localStorage에 변경할 때마다 자동 저장
- 새로고침과 브라우저 재실행 시 할 일 복원
- 테마, 마지막 집중 시간과 날짜별 집중 횟수 저장
- 현재 할 일 목록을 JSON 파일로 내보내기
- JSON 파일을 선택해 할 일 목록 가져오기
- 가져오기 전에 JSON 구조와 각 항목의 필수 값 검사
- 정상 파일도 현재 목록을 교체할지 확인한 뒤 적용
- 검사 실패나 취소 시 현재 목록을 변경하지 않음
- 준비된 한국어 문장 중 오늘의 격언 무작위 표시
- 사용법, 기능, 단계별 개발 과정, 직접 확인한 내용과 한계를 README.md에 기록

안전 조건:
- 가져온 내용은 HTML로 실행하지 않고 일반 글자로 표시해.
- 허용된 카테고리와 중요도인지 검사해.
- 마감일과 생성·수정 시각이 올바른 형식인지 검사해.
- 잘못된 항목 하나라도 있으면 전체 가져오기를 취소하고 이유를 알려 줘.
- 외부 서버, 계정, API와 분석 도구를 추가하지 마.

최종 확인:
1. 추가, 완료, 삭제, 수정 기능
```
